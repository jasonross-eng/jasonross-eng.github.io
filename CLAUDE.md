# Tech Board: notes for Claude

## Who and what
- Elementary technology teacher, grades K-5. Teaches in a room with a Newline board.
- Teacher-only display board, projected in class.
- Live at https://jasonross-eng.github.io (repo jasonross-eng/jasonross-eng.github.io, GitHub Pages from main, root).
- Started as a copy of smithpick/smithpick.github.io. The guides, icons, and weekly plan that came with it are another teacher's and will be trimmed over time.
- New to GitHub. Explain steps in plain words and say exactly what to click.

## Rules
- Public repo and site. No student names, class lists, class codes, or student faces in screenshots. Teacher's own name: keep it off the site (the sub note is signed with no name).
- Kid-facing visuals use real screenshots, not drawings. Kindergartners need to see the exact thing they tap. Exception already in place: the generic Seesaw "Tech Activity" card (guides/2026-11-11-seesaw/3.jpg).
- Low maintenance. Has to survive a low-prep week.
- No em dashes. Short labels. Big text for a projector.
- Work step by step. Don't rework finished parts unless asked. Commit and push after each change.
- Original login-steps.html and login-practice.html stay untouched.

- Top bar, right side (default order): Picker, Scores, Attention (yellow), Draw, Keyboard, Full screen, Arrange, Hide, Start class (green, next to More, as the teacher asked), More. More, then Top bar buttons, lets the teacher move any of these and any More item between the top bar and the More menu and change the order (tbcfg on that device; More, Exit sub mode and Top bar buttons itself never move; Back to how it started resets). The More menu holds Countdown, Background, Clean-up warning, Poll, Hall pass, Dice, Embed a website, Add a picture, QR code, Noise meter, Schedule, Backup and restore, Sub mode.
- Start class: one tap closes any open page, sets and starts the class timer (default "Typing Club" 10 min, changed at the top of the timer's Edit dialog, 0 min turns it off and leaves 5:00), sets voice level 0, clears that grade's Must Do / May Do checks and drawings, and opens Teacher Clarity for the picked grade. Teacher Clarity and Must Do / May Do show the same countdown in a big pill at the top (words, time, progress line; yellow line under 30 s, red and pulsing with Time is up when it ends) whenever the timer is running, paused or just finished, so students still see the timer.
- Clean-up warning: Start class saves the class start time (classstart). Class length (default 45) and warning minutes (default 5, 0 = off) are set in the timer's Edit dialog. When the warning time comes (checked every second), a full-screen red popup says "5 minutes left / Get ready to clean up" with the live countdown and a warning sound, and the main timer switches to a running "Clean up" timer for the time left (it shows on Teacher Clarity and Must Do too). The popup closes on a tap or after 12 s. Warns once per class (classwarned). With the Schedule on, opening or refreshing the board mid-class uses the slot's start time, so the warning still comes on time. No warning if Start class was never tapped and there is no Schedule. Changing it: while a class is running, a small "Clean up at 10:40" button shows under the date (also More, Clean-up warning). It opens a dialog to move this class's warning (-5, -1, +1, +5 min, pick a clock time, Warn now, No warning this class, Back to normal), saved as warnat = "<classstart>|<ms>" (0 = none) and cleared by the next Start class; the same dialog also sets class length and warning minutes for every class. The Clean up timer runs the warning minutes (5 if warnings are off by default) from when it goes off.
- Poll (More, Poll): a floating card like the picker (Arrange moves and resizes it, fill-the-screen button, Close). New poll: Smileys (Good / Okay / Not good), Thumbs (Yes / No) or Multiple choice (2 to 6 typed answers, lettered A to F with colors), optional question, Hide results while voting. Votes are tapped on the board (one tap = one vote); counts and bars per answer; Hide / Show results, Undo, Clear votes, New poll. Saved on that device (poll, pollon, pollrect). Student devices: On (button in the poll) gives the poll a 4 digit code and shows a join box (QR code, the vote.html address, the code, how many devices voted). Students open vote.html (keypad for the code, or ?c=code from the QR), see the question and tap an answer; they can change it. Answers travel through the free public relay ntfy.sh, which the teacher chose: topics jre-tb-<code>-q (the board posts the question, or {closed:true}) and jre-tb-<code>-v (each device posts {n: round, d: random device id, a: answer}); the board listens with EventSource (/sse?since=all) and counts one vote per device per round on top of tapped votes. No names travel. Clear votes and New poll start a new round (new nonce), Close or turning devices off posts closed. Risks told to the teacher: a school filter may block ntfy.sh, ntfy.sh has rate limits shared by the whole school network, and the question text is public to anyone who guesses the code. It could not be tested against the real ntfy.sh from this environment (blocked); it was tested with a fake relay.
- Exit slip: in the poll setup, Save as exit slip stores that poll (any kind, including the new Short answer kind) as exitslip_<grade>. At the clean-up warning, if the grade has one turned on, it opens as the poll with Student devices on and fills the screen, so students see the question, the QR code and the 4 digit code. The Clean-up warning dialog (More, Clean-up warning) shows the grade's exit slip with Turn off / on, Show it now and Remove. Short answer: students type up to 200 characters on vote.html (told not to type names) and send ({n, d, t}); the board lists the answers, hidden until the teacher taps Show answers; sending again replaces a device's answer.
- Hall pass (More, Hall pass): a floating card (makeFloat) with one row per pass: the name with a timer next to it and the place (red and pulsing after the limit, default 8 min, with a toast and a bell once; the card opens itself if closed). When the kiosk says the student is back the row turns green, its timer stops at the time gone, and it says Back! Tap to clear; a row only leaves the board when the teacher taps it (tapping a row that is still out marks the student back). Saved as hplist (old hpout is converted). Then passes today, Log (table, Download log CSV, Clear log) and Kiosk setup. kiosk.html runs on a spare Chromebook or iPad by the door: the teacher downloads a kiosk file (hall-pass-kiosk.json: app hallpass, a random 16 character key, every grade's picker classes with names and a list version) and opens it on the kiosk once (stored there as hpk_cfg). Board and kiosk talk through ntfy.sh on the private topic jre-hp-<key>, sending only a random class id, a position number, the place and times, never a name: hello (kiosk asks), class (board says which grade/class is current; sent on change, checked every second), out, in. The kiosk shows the current class's names, then places (Restroom, Nurse, Locker, Water, Office), then a big I'm back screen; only one student out at a time (others wait); destination screen times out after 30 s; holding the kiosk title for 3 s re-opens setup. Board log (hplog, last 500) and state (hpout) are on that device. A mismatched list version shows "The kiosk has an old class list". Tested only with a fake relay.
- Dice, Embed a website, Add a picture (More): floating cards made by makeFloat() (header with title, fill-the-screen button, Close or Remove; Arrange moves and resizes them; spot saved per card). Dice: 1 to 6 six-sided dice drawn as SVG pips, Roll flashes faces with little clicks for under a second, total shown for 2 or more; saved as dice/diceon. Embed: paste any link (YouTube, Google Slides and Canva links become their embed versions via EMB); some sites refuse to be framed, so Open in tab and Change link are in the header; embedurl/embedon. Pictures: each upload becomes its own card (shrunk to 1600 px JPEG, or 1000 px PNG to keep see-through parts), saved on that device only as imgdata_<id>, list in imgs; Remove asks first. A full device shows "out of room".
- QR code (More): paste a link (and optional words for the top); a full-screen page shows a giant QR code and the link under it. One link per grade, saved on that device. qrcode.js in the repo is the MIT qrcode-generator 1.4.4 library (Kazuhiko Arase), copied in so it works even if the school blocks CDNs.
- Backup and restore (More): Save a backup file downloads every cb_ localStorage key as tech-board-backup-YYYY-MM-DD.json; Restore from a file replaces this device's cb_ keys with the file's and reloads. The file holds student names, so the teacher keeps it private. Nothing is uploaded. Every day: On (off by default) saves a backup automatically on the first tap of each school day (Mon to Fri, not in sub mode), because browsers only allow downloads right after a tap; the dialog shows the last backup date. Getting it into Google Drive is the teacher's side: Google Drive for desktop plus Chrome's download folder set to a Drive folder.
- Attention (top bar): full-screen yellow "Eyes on me!" with a chime; tap to close, closes itself after 15 s; Change words is saved on that device.
- Timer labels: a row of dashed chips in the timer card (default Clean up 2, Brain break 3, Partner work 5); a chip sets the time and shows its words above the countdown; plain minute buttons clear the words; Edit opens a dialog to change them (saved on that device).
- Noise meter: lives in the clock card. A Noise meter button under the voice level buttons (also More, Noise meter) turns it on; a full-width row at the bottom of the clock card shows the level bar with the limit mark, the Too loud count and a settings button (popup: Limit slider, Sound + Test, Reset to 0, Turn off; settings hidden in sub mode). Hidden when the clock card is small, but it still listens and sounds. It uses the microphone only while on; when the level was over the limit for at least half of the last 1.5 s (talking goes up and down, so it does not need to stay over the whole time) it flashes Too loud! and plays the chosen sound (Chime, Bell, Shh, Beep beep, or No sound; made with Web Audio, no files; Test plays it; not again within 5 s). Each time it goes off it adds 1 to the Too loud count (one count per loud spell; it can go off again after about 2 s of quieter room); checked 10 times a second with setInterval, not animation frames, so it keeps working when the board is in another tab; if the browser holds the sound system after a refresh it shows "Tap the board to start the meter" and wakes on the next tap; Reset sets it to 0. Sound and count are saved on that device. Nothing is recorded. Microphone may be blocked by the school.
- Schedule (More): off until turned on. Per weekday (Mon to Fri), rows of start time + grade + picker class (or Any class); Copy this day to another day or every day. While on, when a slot starts the board switches to that grade and picker class and runs Start class (so the class timer starts). On page load it only switches the grade, without Start class, so a reload mid-class does not restart the timer; not in sub mode either. It only switches when a new slot starts, so manual changes stick until the next class. The teacher has different classes every day; if it turns out to be a rotating day cycle (Day 1 to 6) instead of weekdays, it needs reworking. Saved on that device only.
- Sub mode (More): hides Picker, Arrange, Hide, More, the small and big buttons, This week Edit / All pages / week menu, Teacher Clarity and Must Do edit buttons, and the countdown editor. Shows a red Exit sub mode button that asks for the code the teacher picked when turning it on (blank code means no code). Stays on after a reload.
- Show-on-the-board buttons: in the This week Edit there are two boxes, YouTube video and Slides or Canva (each: On/Off, link, button name), saved on that device only, one of each per grade. When On it adds a row to that grade's This week list (movable with Up/Down; its Off button turns it off). Tapping it opens the content inside the board in the full-screen viewer (YouTube through youtube-nocookie.com/embed; Google Slides through /embed; Canva through view?embed), with a strip left at the bottom for Home and an Open in tab button as the fallback. In the Slides or Canva box any other link is accepted and simply opens in a new tab. Not in plans.js.
- Event countdown: a strip that scrolls across the bottom of the home board ("12 school days until Winter Break"). Countdown button in the top bar (or a tap on the strip) opens the editor: On/Off, events (name + date), No school days (date ranges), Reset. Counts weekdays from today up to the day before the event, minus the no school days; shows "Today" on the day; past events drop off on their own. Edits are saved on that device only. Starting list for every device is events.js (COUNTDOWN: on, events, noSchool); it ships empty, so the strip stays hidden until an event is added.
- plans.js: one block per week, keyed by that week's Monday (YYYY-MM-DD). Each week has grades: { "1": { clarity: { will, so, know }, items: [...] }, ... "4", "sp" } ("sp" is the Specials tab). A grade with no items list falls back to a week-level items list if there is one. Optional icon: "icons/name.png" (real app icon cropped from screenshots, rounded square) replaces the number. Board opens to the newest week that has started. Future weeks can be added ahead. Old weeks stay.
- guides.js: step guides. id format YYYY-MM-DD-name. Optional practice: "page.html" adds a yellow Practice button on the guide and a Steps button on that page (Teach Your Monster uses login-practice.html). Images in guides/<guide id>/1.jpg, 2.jpg... Old guides stay and show in All pages.
- keyboard.html: projected Chromebook keyboard (lowercase keys, search key, Chromebook top row). Tap a key to light it orange (tap again to unlight, Clear resets). Typing on a real keyboard flashes that key. Opens as an overlay from anywhere: Keyboard button in the home top bar and next to Draw on guide/practice pages; Close keyboard returns to the same spot. Also works alone at jasonross-eng.github.io/keyboard.html. Drawn, not a screenshot, on purpose.
- sub.html, sub-note.pdf, sub-qr.svg: printable half-sheet sub note with QR code to the board.
- Google Slides links auto-open in present mode.

- Write the three statements for that grade in kid-friendly words (will / so / know: only the ending of each sentence, short enough for the projector), show them in chat, then put them in that week's block in plans.js under that grade's clarity and push.
